A Filosofia do Sistema

O InterceptorSystem não é apenas uma ferramenta de registros; ele é um motor de regras de negócio. Projetado para simplificar e organizar a gestão de segurança patrimonial, terceirização de serviços e facilities.

A premissa básica é a união da operação com o financeiro. O sistema cruza os turnos e faltas (alocações) com os preços de venda definidos nos contratos (tags). O resultado é uma folha e um faturamento sempre exatos.

Arquitetura de Entidades

Como as informações se conectam no banco de dados.

1. O Cliente

O centro do ecossistema. Todo posto, contrato e diária orbita em torno de um cliente.

2. Tags

Representam funções (Ex: Vigilante). Unem o funcionário ao contrato.

3. Contrato

O acordo financeiro. Precifica cada Tag dentro de um cliente ativo.

4. Postos e Alocações

O Posto é o local físico (Ex: Portaria Sul). A Alocação é a vaga na escala daquele posto (Ex: 12x36 Noturno).

5. A Diária

O ápice do sistema. É a união exata de um Funcionário cobrindo uma Alocação num dia específico. Ela consolida faltas, adicionais e financeiro.

O Fluxo de Implementação

A ordem ideal para estruturar um cliente do zero.

01

Cadastro Base

Crie o Cliente. Acesse o menu de clientes e defina os dados básicos empresariais.

02

Contrato & Preços

Dentro do cliente, crie o Contrato. Adicione as Tags de serviço (ex: Vigia) e defina o valor cobrado do cliente por cada posto com essa Tag.

03

Geografia & Escalas

Crie os Postos físicos. Dentro de cada Posto, crie as Alocações (Turnos) necessários para o funcionamento.

04

Equipe

Cadastre os Funcionários atribuindo a eles as mesmas Tags criadas no contrato. Isso garantirá o link na hora do apontamento.

05

Apontamento

Lance as Diárias! Vincule o funcionário X à alocação Y no dia Z. O cálculo é automático.

Conhecimento Tático (FAQ)

Respostas rápidas para problemas complexos.

O que é uma "Dobra Programada"?

Quando um funcionário precisa emendar dois turnos. Por segurança trabalhista, o sistema bloqueia diárias coladas, a menos que a flag de Dobra Programada seja ativada. Lembre-se: é obrigatório conceder o descanso a seguir.

Posso ter mais de um contrato ativo?

Não simultaneamente. Para o mesmo cliente, se houver renovação de valores, você deve finalizar o contrato antigo e ativar o novo.

O assistente "Criação Completa" vale a pena?

Muito! Ele é um Wizard na listagem de clientes que cria de uma vez só: Cliente, Contrato, Tags, Postos e Alocações, economizando dezenas de cliques.
