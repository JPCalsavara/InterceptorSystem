# PLANO DE GESTÃO DO PROJETO

**Projeto:** Ferramenta para upload de ações dos núcleos da RBAC
**Grupo:** Fênix
**Data:** 30/03/2026
**Versão:** v1
**Responsável:** Gabriel Rodrigues dos Reis de Sousa

---

## 1. Objetivo deste plano

Este plano organiza como o projeto do chatbot WhatsApp para a RBAC será gerido nas 10 áreas de conhecimento, servindo como índice central dos planos subsidiários e orientando a equipe sobre abordagem, ferramentas e responsabilidades de gestão ao longo de todo o ciclo do projeto.

## 2. Visão geral da abordagem de gestão

O projeto é conduzido pelo gerente Gabriel Rodrigues, que acompanha o andamento geral por meio de reuniões semanais de status (sábados às 10h ou terças às 19h40, via Google Meet). Cada integrante reporta o trabalho realizado e os próximos passos; impedimentos são resolvidos em reunião ou diretamente via WhatsApp entre os encontros. As tarefas são rastreadas no GitHub Issues com milestones alinhados aos marcos M1–M8. Todos os documentos e atas são armazenados no Google Drive compartilhado da equipe. A comunicação com o cliente (Fabiana/RBAC) é feita com frequência mínima quinzenal por e-mail, com reuniões via Google Meet quando necessário.
