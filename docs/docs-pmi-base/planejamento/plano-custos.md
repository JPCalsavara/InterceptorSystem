## 1. Objetivo deste plano

O objetivo desse plano é deixar claro que o projeto não apresenta custo algum, visto que as ferramentas que serão usadas são gratuitas caso utilizadas da maneira prevista para o produto final.

## 2. O projeto tem custos?

Marcar uma opção:

- (x) Não há custos relevantes (sem compras nem investimentos).
- ( ) Há custos relevantes.

As ferramentas que serão utilizadas são gratuitas.

## 3. Como será montado o orçamento (se houver custos)

O orçamento será montado através de pesquisas de ferramentas que podem ser usadas durante o projeto, dando prioridade para as que são gratuitas.

Todas as ferramentas utilizadas terão seus nomes armazenados em uma planilha.

## 4. Como os custos serão acompanhados

Como as ferramentas são gratuitas não há necessidade de acompanhar os custos, já que os mesmos são 0.

## 5. Tratamento de desvios de custo

Caso haja a necessidade de algum gasto, o cliente será contatado para analisar se o valor faz sentido, e direcionado pelo líder do projeto, decidirão qual caminho tomar a partir daí. Caso o cliente priorize continuar sem gastos, a equipe fará uma pesquisa para encontrar possíveis alternativas gratuitas que substituam a ferramenta que exigisse pagamento.
