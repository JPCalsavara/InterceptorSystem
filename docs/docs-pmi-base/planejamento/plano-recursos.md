## 3. Controle de horas

O controle de horas de trabalho será registrado em uma planilha disponibilizada a todos os membros da equipe. Nesta planilha, será construído tabelas que representam cada semana do mês vigente. Cada mês terá suas respectivas tabelas e páginas.

O registro de horas será feito por cada membro da equipe de forma semanal. O gerente de projetos Gabriel Rodrigues revisará semanalmente as horas trabalhadas.

## 4. Acompanhamento do uso de recursos

O gerente do projeto juntamente com o membro responsável pelo plano de recursos (João Victor Mansano) verificará se a divisão de trabalho está distribuída de forma igualitária.

Caso necessário alteração das tarefas, será feita uma reunião com todos os membros para reorganização e distribuição de tarefas. O membro João deverá apresentar o motivo das mudanças.

## 5. Atualização deste plano

O plano de recursos pode ser alterado caso algum dos motivos a seguir ocorra:

- Saída/Entrada de algum membro;
- Queixas referente à sobrecarga de algum membro;
- Pedidos de mudança de papéis;
- Surgimento de novas responsabilidades no papel de algum membro.

É importante ressaltar que, todos os motivos acima devem ser validados pelo gerente do projeto. A partir de seu aval, será agendada uma reunião conforme citado no tópico "4. Acompanhamento do uso de recursos".
