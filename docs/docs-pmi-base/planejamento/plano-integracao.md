---

## 1. Objetivo deste plano

Este plano define como o projeto de desenvolvimento do chatbot WhatsApp para a Rede Brasileira de Aprendizagem Criativa (RBAC) será coordenado de forma integrada entre os integrantes do Grupo Fênix. O gerente do projeto acompanhará o andamento geral por meio de reuniões semanais, nas quais cada integrante reportará o trabalho realizado e os próximos passos. Todas as decisões relevantes serão registradas de forma centralizada, garantindo rastreabilidade e alinhamento contínuo entre a equipe e o cliente.

## 2. Como o projeto será coordenado

- **Como serão definidas as principais decisões do projeto:** As decisões técnicas e de escopo serão debatidas entre os membros da respectiva área e comunicadas ao gerente, que deve participar de todas as decisões relevantes e ter ciência de tudo o que acontece no projeto. Em situações urgentes entre reuniões, o gerente decide e notifica a equipe imediatamente via WhatsApp. O acompanhamento das tarefas será feito por meio do GitHub Issues com milestones, integrado ao repositório de código do projeto, com visibilidade para toda a equipe.
- **Como será feito o registro das decisões:** Atas de reunião registradas no Google Drive compartilhado da equipe. Mudanças que impactam escopo, prazo ou custo serão refletidas nos documentos correspondentes com atualização de versão (ex.: v1 → v2).

## 3. Monitoramento e controle geral do projeto

- **Quem vai acompanhar o andamento geral:** Gabriel Rodrigues (Gerente do Projeto), com reporte de todos os integrantes nas reuniões semanais.
- **Frequência do acompanhamento:** Semanal, nas reuniões de status. Reuniões extraordinárias poderão ser convocadas conforme necessidade.
- **Informações verificadas a cada reunião:**
  - **Escopo:** as entregas estão dentro do escopo definido (chatbot MVP, integração WhatsApp/Google Sheets/Drive)?
  - **Prazo:** as atividades estão dentro do cronograma? Algum marco (M1–M8) em risco?
  - **Qualidade:** os requisitos funcionais e não funcionais estão sendo respeitados?
  - **Riscos:** algum risco mapeado se materializou? Há novos riscos?
  - **Recursos:** a carga de trabalho está equilibrada entre os integrantes?
