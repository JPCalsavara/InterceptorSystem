## 1. Objetivo deste plano

O objetivo desse plano é deixar claro que as ferramentas utilizadas no projeto serão gratuitas e que o projeto não terá a necessidade de aquisições.

## 2. O projeto tem aquisições?

Marcar uma opção:

- (x) Não tem nenhuma compra nem contrato formal.
- ( ) Tem compras ou contratos.

Ferramentas gratuitas, sem a necessidade de aquisições.

## 3. Acompanhamento de aquisições

Como o projeto não terá aquisições, não há necessidade de acompanhamento.

## 4. Encerramento de aquisições

Caso em algum momento seja necessário alguma aquisição, a mesma será passada para o cliente, caso o cliente decida não realizar tal aquisição, será pesquisado uma ferramenta semelhante que não tem necessidade de compra.
