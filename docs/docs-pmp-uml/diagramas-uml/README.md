# Diagramas UML - InterceptorSystem

Esta pasta contem os diagramas UML em formato `.md` usando Mermaid.

## Regras

- Manter nome dos arquivos em padrao UNIX (minusculas + kebab-case).
- Manter os diagramas em blocos Mermaid dentro de arquivos `.md`.
- Quando necessario gerar imagem para apresentacao externa, exportar a partir do `.md` sem perder a fonte.
